# Domain Docs

Single-context repo: one product.

## Before exploring, read these

- `docs/architecture.md`: packages, the Session model, adapter rules
- `docs/decisions.md`: settled decisions (this repo's ADR log)
- `docs/naming.md`: how the name was chosen (historical)
- `docs/research/`: findings from research tickets
- Issue [#45](https://github.com/JarenKempton/quench/issues/45): current direction and scope

## Where decisions are recorded

Append settled decisions to `docs/decisions.md`. Wayfinder decisions are also recorded on
their GitHub ticket.
